---
description: Set the language everything is answered in
argument-hint: "<code>  e.g. en, de, es, tr"
---

Set the oduncu language to $ARGUMENTS. The four strings and every prose answer switch to that language together and stay there, even if the user keeps writing in another one. Derive the four from their roles — first-person "I will do it" with a trailing ellipsis, "done", "tried, could not", "will not" — keeping the failure and refusal words distinguishable. `tr` restores the default pair: Turkish strings, prose in the user's own language.
