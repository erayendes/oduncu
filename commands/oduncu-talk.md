---
description: Trace on — the completion line carries the changed file paths
---

Turn the oduncu trace on. From now on the completion line lists the relative paths of files actually written that turn, comma separated, e.g. `tamam. src/auth.js, src/auth.test.js`. Over four paths, print the first three plus `+N`. Neither `yapamadım.` nor `yapamam.` ever carries a trace. Leave mode and language untouched.
